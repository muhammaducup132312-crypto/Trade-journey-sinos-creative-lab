Mode pencatatan & impor MT5

Gunakan satu jurnal untuk berbagai sumber transaksi.

Manual: catat transaksi sendiri.
Kalkulasi otomatis: hitung estimasi P/L dari entry, exit, lot, dan nilai kontrak yang kamu tentukan.
Integrasi MT5: untuk versi lokal ini tersedia impor file CSV. Duplikat dilewati, trade baru otomatis ditandai Perlu review. Koneksi langsung ke terminal MT5 butuh EA + server (belum aktif).

Ekspor riwayat akun dari MT5 terlebih dahulu. Format laporan berbeda-beda, jadi periksa hasil impor sebelum mengandalkan statistiknya. File diproses di browser dan tidak diunggah ke server.

Pilih satu atau beberapa screenshot riwayat trade. Claude membacanya dan menambahkan trade-nya.

Backup & data pribadi

Semua data disimpan di perangkat/browser ini.

Tidak ada login atau server. Gunakan ekspor JSON untuk backup lengkap termasuk strategi. CSV cocok untuk membuka jurnal di spreadsheet.

Peringatan: menghapus data browser dapat menghapus jurnal. Backup berkala sangat disarankan.

Pengaturan kalkulasi

Sesuaikan estimasi pip dan nilai pip untuk instrumenmu.

XAUUSD, JPY, dan CFD bisa punya konvensi pip berbeda. Sesuaikan ukuran pip dan nilai pip dengan spesifikasi broker. Nilai kalkulasi adalah estimasi sebelum komisi/swap kecuali kamu memasukkannya.
